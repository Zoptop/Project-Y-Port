- **CloakSuit flags** (combat §1.3 shows "–"): `CUnitCloakSuit::init` shows `*(char**)(+0x5c) = "articleSystem4saveEP7__sFILE"`. This is Ghidra rendering the constant as a string pointer. The string sits at file offset 0x78e57, which is Ghidra address 0x88e57, so the flags are **0x88e57** (0xe57 | 0x8000 never-auto-target | 0x80000 not-smoking).
- **Call for help** (combat §3.1 step 10): the `dist² < 9000` test is between the helper and the **attacker** (`CGameObject::squaredDistance(helper, attacker)`), not the victim.
